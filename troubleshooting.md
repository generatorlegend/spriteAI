## API Rate Limits

### Error: Too Many Requests

**Cause**: You've exceeded the rate limit for API calls to the OpenAI service.

**Solution**: 
1. Implement exponential backoff in your requests.
2. Catch the error and wait before retrying:

```javascript
try {
  await generateCharacterSpritesheet(description, options);
} catch (error) {
  if (error.response && error.response.status === 429) {
    console.log('Rate limit exceeded. Waiting before retrying...');
    await new Promise(resolve => setTimeout(resolve, 60000)); // Wait for 1 minute
    // Retry the request
  } else {
    throw error;
  }
}
```

3. Consider upgrading your OpenAI plan for higher rate limits.

## Image Processing Errors

### Error: Unable to process image

**Cause**: The image generated by DALL-E might not be in the expected format or might be corrupted.

**Solution**:
1. Check if the image URL is accessible:

```javascript
const checkImageUrl = async (url) => {
  try {
    const response = await axios.head(url);
    return response.status === 200;
  } catch (error) {
    return false;
  }
};
```

2. If the URL is inaccessible, regenerate the image:

```javascript
if (!(await checkImageUrl(response.data[0].url))) {
  console.log('Image URL is inaccessible. Regenerating...');
  // Call the generate function again
}
```

### Error: Sharp pipeline error

**Cause**: Issues with image processing using the Sharp library.

**Solution**:
1. Ensure you have the latest version of Sharp installed.
2. Check if the input image is valid:

```javascript
try {
  await sharp(imgBuffer).metadata();
} catch (error) {
  console.error('Invalid image buffer:', error);
  // Handle the error (e.g., regenerate the image)
}
```

## Integration Problems

### Error: Module not found

**Cause**: The SpriteAI library or its dependencies are not properly installed or imported.

**Solution**:
1. Ensure SpriteAI is installed:
   ```
   npm install spriteai
   ```
2. Check your import statement:
   ```javascript
   import { generateCharacterSpritesheet, generateEnvironmentSprites } from 'spriteai';
   ```
3. Verify that all dependencies are installed:
   ```
   npm install openai axios sharp jimp
   ```

### Error: OpenAI API key not found

**Cause**: The OpenAI API key is not set or is invalid.

**Solution**:
1. Set your OpenAI API key as an environment variable:
   ```
   export OPENAI_API_KEY=your_api_key_here
   ```
2. Or, set it programmatically (not recommended for production):
   ```javascript
   import OpenAI from 'openai';
   const openai = new OpenAI({ apiKey: 'your_api_key_here' });
   ```

## Other Common Issues

### Inconsistent Sprite Sizes

**Issue**: Generated sprites have inconsistent sizes across frames.

**Solution**:
1. Specify a consistent size in the options:
   ```javascript
   const options = {
     size: '64x64',
     framesPerState: 6
   };
   ```
2. Post-process the sprites to ensure uniform size:
   ```javascript
   const uniformSize = async (buffer, targetSize) => {
     return sharp(buffer)
       .resize(targetSize, targetSize, { fit: 'contain', background: { r: 0, g: 0, b: 0, alpha: 0 } })
       .toBuffer();
   };
   ```

### Poor Image Quality

**Issue**: Generated sprites have low quality or unwanted artifacts.

**Solution**:
1. Experiment with different size options:
   ```javascript
   const options = {
     size: '1024x1024', // Try larger sizes for better quality
     style: 'pixel-art' // Adjust style as needed
   };
   ```
2. Use post-processing to enhance image quality:
   ```javascript
   const enhanceImage = async (buffer) => {
     return sharp(buffer)
       .sharpen()
       .toBuffer();
   };
   ```
