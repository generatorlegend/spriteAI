## Customizing Sprite Generation

SpriteAI offers powerful customization options for generating character spritesheets and environment sprites. Let's explore some advanced techniques to fine-tune your sprite generation process.

### Character Spritesheets

The `generateCharacterSpritesheet` function allows for extensive customization. Here's an example of how to use advanced options:

```javascript
import { generateCharacterSpritesheet } from 'spriteAI';

const customCharacter = await generateCharacterSpritesheet('cyberpunk ninja', {
  states: ['idle', 'run', 'jump', 'attack', 'die'],
  framesPerState: 8,
  size: '2048x2048',
  style: 'pixel-art',
  padding: 2,
  direction: 'left',
  save: true
});

console.log(customCharacter.metadata);
```

In this example, we're creating a cyberpunk ninja character with custom animation states, more frames per state, larger size, and facing left.

### Environment Sprites

For environment sprites, use the `generateEnvironmentSprites` function with custom options:

```javascript
import { generateEnvironmentSprites } from 'spriteAI';

const customEnvironment = await generateEnvironmentSprites('futuristic cityscape', {
  elements: 6,
  size: '2048x2048',
  style: 'vector',
  padding: 3,
  theme: 'sci-fi'
});

console.log(customEnvironment.metadata);
```

This generates a futuristic cityscape with 6 distinct elements in a vector style, suitable for a sci-fi game.

## Working with Different Art Styles

SpriteAI supports various art styles. You can fetch available styles using the `fetchAvailableSpriteStyles` function:

```javascript
import { fetchAvailableSpriteStyles } from 'spriteAI';

const availableStyles = await fetchAvailableSpriteStyles();
console.log(availableStyles); // ['pixel-art', 'vector', '3d', 'hand-drawn', 'anime']
```

To create sprites in different styles, simply specify the style in the options:

```javascript
const animeCharacter = await generateCharacterSpritesheet('magical girl', {
  style: 'anime',
  states: ['transform', 'cast_spell', 'fly']
});

const vector3DEnvironment = await generateEnvironmentSprites('space station interior', {
  style: '3d',
  theme: 'sci-fi'
});
```

## Optimizing Performance for Batch Processing

When generating multiple sprites, consider using Promise.all for parallel processing:

```javascript
async function batchGenerateCharacters(descriptions) {
  const promises = descriptions.map(desc => 
    generateCharacterSpritesheet(desc, { save: true })
  );
  return await Promise.all(promises);
}

const characters = await batchGenerateCharacters([
  'warrior orc',
  'elven archer',
  'dwarven blacksmith'
]);
```

## Integrating SpriteAI Output into Game Development Workflows

### Using Spritesheets in Game Engines

Most game engines can directly use the spritesheets generated by SpriteAI. Here's an example of how you might use the metadata in a game engine:

```javascript
const character = await generateCharacterSpritesheet('knight');

// In your game engine:
const spritesheet = new Spritesheet(character.spritesheet);
const idleAnimation = spritesheet.createAnimation({
  frames: character.metadata.frameData.idle.frames,
  frameRate: 10,
  repeat: -1
});

player.setAnimation('idle', idleAnimation);
```

### Automating Asset Pipeline

You can create a script to automatically generate and organize sprites for your game:

```javascript
async function generateGameAssets() {
  const characters = [
    { name: 'hero', description: 'brave knight' },
    { name: 'enemy', description: 'evil sorcerer' }
  ];
  
  const environments = [
    { name: 'forest', description: 'lush magical forest' },
    { name: 'dungeon', description: 'dark mysterious dungeon' }
  ];

  for (let char of characters) {
    const sprite = await generateCharacterSpritesheet(char.description, { save: true });
    // Save metadata to a JSON file
    fs.writeFileSync(`./assets/${char.name}_metadata.json`, JSON.stringify(sprite.metadata));
  }

  for (let env of environments) {
    const sprite = await generateEnvironmentSprites(env.description, { save: true });
    fs.writeFileSync(`./assets/${env.name}_metadata.json`, JSON.stringify(sprite.metadata));
  }
}

generateGameAssets();
```

## Advanced Techniques and Best Practices

### Custom Background Removal

For more control over background removal, use the `removeBackgroundColor` function directly:

```javascript
import { removeBackgroundColor } from 'spriteAI';

await removeBackgroundColor(
  'input.png',
  'output.png',
  '#FFFFFF',  // Target color
  0.1         // Color threshold
);
```

### Optimizing Prompts for Better Results

When describing sprites, be specific and consistent. For example:

- Bad: "Create a character"
- Good: "Create a pixel-art warrior character with plate armor and a large sword, facing right"

### Error Handling and Retries

Implement robust error handling and retry logic for production use:

```javascript
async function generateWithRetry(description, options, maxRetries = 3) {
  for (let i = 0; i < maxRetries; i++) {
    try {
      return await generateCharacterSpritesheet(description, options);
    } catch (error) {
      console.error(`Attempt ${i + 1} failed: ${error.message}`);
      if (i === maxRetries - 1) throw error;
    }
  }
}
```
